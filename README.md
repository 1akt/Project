Last year, my friend developed a 2D dungeon crawler project featuring randomly generated rooms for each level. He showcased his work in this video: https://www.youtube.com/watch?v=74l-9pMIP90.

The code behind his project is in the file 'FriendProject.py', which is the basis for the game in the video. Inspired by his work, I’ve started building my own version, called 'vampire_hunter_game.py'. While neither of these codes are fully functional at the moment, my end goal is to create a game identical to my friend's project, with just a few differences: my main character is a vampire hunter, and the enemies are vampires. Additionally, I plan on adding a werewolf boss in the fifth room. But each rooms layout should be randomly generated.
