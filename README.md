Last year, my friend developed a 2D dungeon crawler project featuring randomly generated rooms for each level. He showcased his work in this video: https://www.youtube.com/watch?v=74l-9pMIP90.

Inspired by his project, I’m building a similar game. However, in my version, the main character is a vampire hunter, and the enemies lurking in the dungeon are vampires. To make things more intense, a werewolf boss awaits in the fifth room of the dungeon.
